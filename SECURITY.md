# Security policy

Report a suspected vulnerability by email to paul@parkscomputing.com, not in a public issue. Include the input that triggers it and the version. A parser must never crash, hang, run out of memory or read outside its input on any document, so a document that does any of those is a vulnerability even if it is invalid.

Reports are acknowledged within seven days. This project has no released version yet, and no version is supported until 1.0.0 is published.
